# Cable Advisor

A free preliminary cable sizing PWA for engineers, based on IEC 60364 calculation approach.

## Features

- Load current input
- Voltage drop estimation
- Cable material selection
- Insulation type selection
- Ambient temperature input
- Grouped circuit input
- Short-circuit withstand check
- Mobile-friendly PWA interface

## Disclaimer

This tool is intended for learning and preliminary engineering estimation only.
Final cable sizing must be verified by qualified engineers according to project specifications, local regulations, and applicable standards.
